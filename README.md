## Learning Path

A practical progression through this **CTF lab collection**:

1. Start with **Noob File Hunt** to build basic file-discovery skills.
2. Explore **ROT13 Relay** and **ROT13 After the Rainbow** for encoding fundamentals.
3. Move into **Hidden Echoes** and the pixel-focused investigation lab.
4. Continue with the **StegTrail** and **Steg Sleuth** challenges.
5. Investigate RAR archives and digital artifacts.
6. Study **Noob SSH Pivot** and **Reuse Chain 2** to connect discovery with access and credential-security concepts.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Read the objective and identify the expected type of evidence.
2. Inspect relevant files or application data.
3. Determine whether information is encoded, hidden, archived, or embedded.
4. Use appropriate analysis techniques within the authorized lab.
5. Document findings and preserve useful evidence.
6. Explain how the discovered weakness or artifact relates to real-world security.
7. Record lessons learned for future CTF and defensive-security work.

Never investigate or access files on systems without permission.
